# Avvikelse (test)

Återanvänder Avvikelse med utkast, kompletta partsfält och övriga parter aktiverade. Används av befintliga registreringsscenarier i Playwright. Kräver `--test` i Katla-kommandona eller `TEST=true` vid ett uttryckligt frontendtestbygge. Backend kräver `ALLOW_TEST_KATLA=true` i lokal/testkörning. Får aldrig publiceras i katalogen.
